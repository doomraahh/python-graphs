# Построение графиков функций и диаграмм на Python

Практическое задание: построить графики элементарных функций и диаграммы с помощью библиотеки **matplotlib**.
Все графики подписаны: есть название графика, подписи осей и легенда.

## Задание

Построить графики:

| № | Что строим | Функция в коде |
|---|-----------|----------------|
| 1 | y = kx (линейная, k = 2) | `linear` |
| 2 | y = x² | `square` |
| 3 | y = x³ | `cube` |
| 4 | y = k/x (гипербола, k = 4) | `hyperbola` |
| 5 | y = eˣ | `exponent` |
| 6 | y = sin x | `sine` |
| 7 | y = tg x | `tangent` |
| 8 | y = ctg x | `cotangent` |
| 9 | y = th x (гиперболический тангенс) | `tanh` |
| 10 | y = ln x | `ln` |
| 11 | график нормального распределения | `normal` |
| 12 | горизонтальная гистограмма | `barh` |
| 13 | круговая диаграмма | `pie` |
| 14 | с помощью `subplot` собрать полотна (см. ниже) | `canvas_6`, `canvas_7` |

**Полотна (п. 14):**
1. Полотно из 6 графиков (сетка 2×3) — графики №1–6.
2. Полотно из 7 графиков (сетка 2×4 через `GridSpec`) — графики №7–13, при этом первый график (tg x) занимает 2 секции.

Всего 13 графиков = 6 + 7, поэтому каждый график попадает ровно на одно полотно.

> Примечание: часть пунктов (8, 9, 11–13) в исходном списке была плохо читаема, поэтому они истолкованы по смыслу:
> ctg x, th x (tanh), нормальное распределение, горизонтальная гистограмма, круговая диаграмма.
> Данные для гистограммы и круговой диаграммы — учебные (популярность языков программирования).

## Запуск

Нужен Python 3.9+.

```bash
pip install -r requirements.txt
python main.py
```

Программа сохранит картинки в папку `output/` и покажет окна с графиками
(окна закрывайте по очереди).

## Структура проекта

```
main.py            весь код: функции построения графиков и два полотна
requirements.txt   зависимости (numpy, matplotlib)
output/            готовые графики (PNG)
  01_linear.png ... 13_pie.png   одиночные графики
  14_canvas_6.png                полотно из 6 графиков
  15_canvas_7.png                полотно из 7 графиков
```

## Как устроен код

- Каждая функция (`linear`, `square`, …) рисует один график на переданной оси `ax`,
  поэтому её можно использовать и отдельно, и внутри полотна.
- `finish()` подписывает заголовок и оси и рисует оси координат.
- У `tg x` и `ctg x` значения у асимптот заменяются на `NaN`, чтобы не было вертикальных соединительных линий;
  у `k/x` ветки рисуются отдельно.
- `canvas_6` — `plt.subplots(2, 3)`; `canvas_7` — `GridSpec(2, 4)`, где первый график занимает ячейки `gs[0, 0:2]`.
